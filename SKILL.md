## Workflow
**Always finish in CapCut** (user rule): every HAUS talking-head video is assembled, previewed and (when asked) exported in the CapCut project. Never deliver a final video rendered by ffmpeg/HyperFrames on its own; those renders are only the clips that go into CapCut. Create one CapCut project per video and keep updating that same draft each round.

**Project naming (user rule, mandatory):** CapCut auto-names new projects with numbers or dates (e.g. `1114`). Right after creating a project, rename it to the video's exact title taken from the raw filename (home page → right-click the project card → Rename), e.g. `Audit Confirmation.mp4` → **Audit Confirmation**. Duplicates and tests get a suffix, e.g. **Audit Confirmation - FX Test**. The export uses the same name plus "- Final" (**Audit Confirmation - Final**). The draft folder may keep its old id, so find it via `root_meta_info.json` / `capcut_swap.py <draft> list`. Never leave a project named as a number.
Work in a project folder (e.g. `<project>/`), with `S=%USERPROFILE%\.claude\skills\haus-talking-head`, `O=$S\onboarding`.

0. **Background removal = BiRefNet on the ORIGINAL camera footage, after cutting** (user rule 2026-11-19, replaces the CapCut Remove BG + sharpen_restore route): work from the untouched raw video for transcribe/cut (steps 1-3 use `raw.mp4`, the project's copy of the raw). After the final cut and the pause loop, run the cutout on the cut: `python $S/scripts/final_clean_bi.py cut.mp4 bg.png cut_clean.mp4` (BiRefNet-portrait on the RTX 3060, ~55 min per 2.5 min). Her whole body stays the untouched camera pixels (full sharpness, perfectly in sync), hair edges are clean, and the chair and real room become the brand background `Downloads\Evolution Haus\Evolution Haus Raw Videos\background.png`. Test first: `... x <5-6 times incl. a hand gesture>` and zoom both arm edges + the hair edge. Run the full pass in 30 s chunks launched detached (crash-safe; see Pitfalls for the frame-exact join), then confirm the joined frame count equals the cut's and her face matches the cut frame-for-frame at several points through the WHOLE video. `cut_clean.mp4` is what goes into CapCut and into `morph_composite.py`.
   - **NEVER blend CapCut frames with camera frames** (user rule 2026-11-19: "it's messing up the quality"). No `sharpen_restore.py`, no CapCut Remove BG export as a source for her pixels. CapCut exports at 30 fps vs the camera's 29.97, so any per-frame mix drifts and builds her face from two moments (warped mouth/jaw). `sharpen_restore.py`, `chair_clean.py` and the CapCut-export route are retired.
1. **Transcribe**: `python $S/scripts/transcribe.py raw.mp4 raw_words.json` (also prints timestamped lines).
2. **Choose the keep ranges** (`keep.json`, source seconds): best take of every line, drop stumbles, filler ("um", "okay"), repeated phrases (e.g. "more impact, more impact" → keep one), and **anything showing her starting or stopping the recording** (leaning/reaching to the camera at the start/end or between takes). Check with an ffmpeg contact sheet of the frame just before every join and of the first/last 2 s.
   **Hidden retakes**: whisper silently merges restarts into one clean sentence ("Hi, I'm Melissa... hi, I'm Melissa", "If you stepped away... if you stepped away", "the... the woman"). Before cutting, split every keep range at its pauses (>0.3 s) and transcribe each chunk ON ITS OWN (`condition_on_previous_text=False`); drop any chunk that repeats or false-starts. The user caught these by ear, so never skip this.
3. **Cut**: `python $S/scripts/cut.py raw.mp4 keep.json cut.mp4` (tightens pauses, 12 ms audio fades). Re-transcribe the cut: `python $S/scripts/transcribe.py cut.mp4 cut_words.json`.
   **Then remove ALL pauses (mandatory, user rule 2026-11-15)**: no dead air anywhere, not mid-sentence and not between sentences. `cut.py` alone misses pauses with a breath or room noise above -38 dB (the user caught "the good stuff … [2 s] … instead of the basics"), and whisper hides them by stretching a word across the gap ("instead" 31.58-35.04). Loop:
   `python $S/scripts/find_pauses.py raw.mp4 keep.json cut.mp4.segs.json cut_words.json keep_v2.json` → `cut.py raw.mp4 keep_v2.json cut_v2.mp4` → `transcribe.py cut_v2.mp4 cut_words_v2.json` → run `find_pauses.py` again on the new files; repeat until it prints **0 pauses removed** (usually 2 passes). It flags every word gap > 0.25 s and every word > 0.8 s, finds the real silence in the source at -32 dB, splits ranges around pauses inside a sentence and trims the tail/head of ranges at sentence joins, leaving ~0.1 s of air. After the last pass, read the new transcript: every word must still be there (a too-tight trim can clip a soft first word like "If" or "On"; if one is clipped, move that range start back 0.1 s and re-cut). On Audit Confirmation this took the cut from 47.3 s to 43.3 s.
4. **CapCut base**: in the same CapCut project, add the cut (`cut.mp4`, already background-replaced and chair-free) at 0:00. There is NO background-image track (the background is baked into the cut). **Never run CapCut Remove BG on the cut** and never on a swapped file. Turn on **Proxy** (Details → Modify → Performance) for smooth preview. The same `cut.mp4` feeds the split windows (`morph_composite.py ... cut.mp4 ...`); no separate matte step is needed.

## Pitfalls already solved
- **Disk space / page file (Audit Call, 2026-11-18/19)**: the BiRefNet GPU job reserves ~12-18 GB of virtual memory, so Windows grows `pagefile.sys` (seen at 25-28 GB) and the C: drive can drop to ~0 free mid-render; CapCut also refuses to export with < 6 GB free. Before a long render: check free space (`df -h /c`) and the page file (`Win32_PageFileUsage`); if space is low, ask the user for a FULL Windows restart (Start > Power > Restart; confirm via `LastBootUpTime`, and note the page file size is the real test) and to close heavy apps (Figma, CapCut, ChatGPT). Lower the model's reservation with `SessionOptions(enable_cpu_mem_arena=False, enable_mem_pattern=False)` + CUDA `arena_extend_strategy: kSameAsRequested` (done in `final_clean_bi.py`). Never delete files to make room without showing the list and getting the user's yes.
- **Distorted face from ~0:17 on (user saw it 2026-11-19)**: CapCut exports at exactly 30 fps while the camera footage is 29.97 fps, so `sharpen_restore.py` (which blends raw + CapCut frames) drifts by a frame as the video goes on and builds her face from two neighbouring frames. Current standard instead: cut the ORIGINAL raw with `cut.py raw.mp4 keep.json cut_r.mp4`, then run `final_clean_bi.py cut_r.mp4 bg.png cut_clean.mp4` (BiRefNet on the GPU): her whole body is the untouched camera pixels, perfectly in sync, with clean hair, no chair and no CapCut frames. Run it in 30 s chunks (crash-safe) and join with frame-exact trimming (each chunk after the first repeats the boundary frame; chunks 3+ also repeat the previous chunk's last frame), then confirm the joined frame count equals the cut's. If you ever do use a CapCut export again, export it at the camera's frame rate (29.97), never 30.
- **Faint chair outline beside her arm** (user saw it 2026-11-18, even after chair_clean): CapCut leaves a thin semi-transparent grey arc of the chair edge next to her right arm. Colour rules and static-mask tricks can't separate it from her pale blazer (both cut into her arm when tried). Fix: after the final cut, run `python $S/scripts/final_clean_bi.py cut.mp4 bg.png cut_clean.mp4` (BiRefNet on the GPU, keeps her raw detail, everything else = brand bg; test first with `... x 9.0,9.4,96` and check both sleeves), then use `cut_clean.mp4` for CapCut and morph_composite. If a GPU job dies with a numpy MemoryError or the C: drive suddenly reads 0 free, RAM ran out (Windows grew the page file): wait for memory to free and relaunch.
- **Dark notches on the sleeve edges** (user saw them 2026-11-18): an older `chair_clean.py` swapped her pink-grey blazer shadows for the background inside the chair zones, and where the background is the dark table that left black spots along her arms. Fixed in the script (dark pixels only, V < 112, big connected areas only, so the mic's "dji" text is safe). After chair_clean, always check the sleeve edges on both sides in a few frames, not only that the chair is gone.
- **Keep it sharp** (user saw pixelation 2026-11-13): footage inside the overlay is compressed twice (morph, then blend). `morph_composite.py` now writes ProRes qscale 4 and `blend_slots.py` qscale 10 (override with env `PRORES_Q`); never go back to qscale 30. `blend_slots.py` keeps the overlay's SFX audio (`-map 0:a?`). If CapCut preview still looks soft, set preview quality to High or turn Proxy off before judging.
- Final CapCut export: Resolution 1080p, **Bit rate: Highest** (not the default "Higher"), H.264, 30 fps, MP4.
- Cleanup must keep the raw copy and `pops_vN.mov` (the raw, un-morphed overlay) for the current round: morph_composite needs it, and re-rendering costs 5 min.
- `rembg` sessions don't load the CUDA DLLs on their own: GPU scripts must call `onnxruntime.preload_dlls()` first (matte_bi.py does), or they silently run on the CPU.
- Long jobs (matte ~1 h): tell the user the time estimate before starting; launch detached (.bat + `Start-Process`) so a paused session doesn't kill them; a killed matte cannot resume (the mp4 has no moov atom).
- CapCut file dialog: Ctrl+A is blocked; type `"a.mp4" "b.mov" ...` into the File name box to multi-import. The Delete key may not reach CapCut; use the toolbar trash icon.
- Bash `printf` turns `\U`, `\b` in Windows paths into escapes: copy assets into the project and use relative paths in generated .bat files.
- CapCut: keystrokes land in Claude unless CapCut is clicked first; re-run `request_access` for `capcut.exe` after every restart; it may open on the second monitor or minimised (restore with Win32 ShowWindow 9).
- Draft JSON exists twice (`draft_content.json` and `Timelines/<id>/draft_content.json`): edit both with CapCut closed (`capcut_swap.py` does this and backs up).
- lib.mjs CSS owns `#l1/#l2` ids (radial gradients): never use those ids in scenes.
- GSAP overwrites CSS `transform`: centre with `gsap.set(el,{xPercent:-50})`, not CSS translate.
- `faster-whisper` file decode fails with this PyAV: pass a numpy array (transcribe.py does).
- Lint `overlapping_gsap_tweens`/`clip_ends_past_root_duration`: keep SFX inside the scene duration.
